# Student Internship Work Sample

## Overview

This page accompanies a student report produced during the first two
weeks of the UBT-CERT internship program. It provides an English
overview of the original Albanian document and explains its relevance
to this leadership and teaching portfolio.

**Original title:** Simulimi dhe testimi në rrjetë, aplikacione dhe sisteme  
**English translation:** Simulation and Testing in Networks, Applications, and Systems  
**Report date:** April 18, 2017  
**Length:** 22 pages  
**Language:** Albanian  
**Program:** UBT-CERT Internship, Weeks 1–2

## Assignment and Activities

The report presents introductory cybersecurity concepts alongside
practical exercises, screenshots, and security recommendations.
Its stated purpose emphasizes defensive security, vulnerability
identification, and examination of security mechanisms.

The documented activities include:

- Network discovery and information gathering using tools such as
  ping and SmartWhois.
- Host discovery, network mapping, and vulnerability-scanning
  activities using IP scanning tools, Friendly Pinger, and Nessus.
- Enumeration of systems, services, and user information.
- Examination of account security, NTFS alternate data streams,
  and file-hiding techniques.
- Inspection of network connections and startup entries using
  TCPView and Autoruns.
- Traffic observation using Wireshark and related network tools.
- Discussion of malware, social engineering, denial of service,
  and defensive recommendations.

The report combines completed demonstrations with brief explanations
and some unfinished exercise notes. It should therefore be read as
an early internship work sample.

## My Role

As UBT-CERT founder and CERT Manager, I designed the internship
activities and helped establish the laboratory environment supporting
student practice.

The report explicitly credits me, Atdhe Buja, as the assisting
CERT Manager. It provides a historical example of student work
developed within the program I led.

The students authored the report. My contribution was to the
internship program, laboratory development, and guidance supporting
their work.

## What This Sample Demonstrates

The report shows students documenting technical activities through
written explanations and screenshots, then attempting to connect
their observations with security recommendations.

For this portfolio, it illustrates my experience creating a setting
for practical cybersecurity education and supporting collaborative
student work.

The report does not contain a formal grading rubric, recorded
instructor feedback, or measured learning outcomes. It is included
as evidence of student activity and program delivery, rather than
as proof of assessed proficiency.

## Historical and Editorial Context

This is a historical document from 2017. Tool versions, terminology,
and recommendations reflect the period and the students’ stage
of learning.

Some explanations are simplified, and some exercises are incomplete.
The report is not presented as a current technical guide or an
institutional security standard. For example, changing default
service ports alone does not establish that a system is secure.

The original Albanian wording is retained to preserve the student
work. This English overview is a retrospective summary, not a
complete translation.
